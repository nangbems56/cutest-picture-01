"Mochi the Moon Bunny": a chubby cream bunny with huge glossy eyes, blush cheeks, a star hairpin and a tiny carrot, drawn entirely in code. One pure-Python program (standard library only) paints supersampled vector shapes - ellipses, polygons and stamped curves - in a soft pastel palette, then downsamples to a clean 1024x1024 PNG. Deterministic to the byte.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024x1024).
